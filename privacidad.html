Privacidad

Cómo tratamos tus datos.

Qué datos usa esta web

  • Esta web no usa cookies, ni herramientas de análisis o publicidad, ni formularios.
  • No pedimos ni guardamos datos personales de quienes la visitan.
  • Si nos escribís por WhatsApp o Instagram, esos servicios aplican sus propias políticas de privacidad.
  • Si hacés una donación, se procesa en PayPal, que aplica su propia política. Esta web no recibe tus datos de pago.
  • La web está alojada en GitHub Pages, que puede registrar datos técnicos de las visitas, como la dirección IP, según sus propias políticas.

Si tenés dudas, escribinos desde la página de contacto.
